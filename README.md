# FallingSand

A small example project built with the [BRUTAL framework](https://github.com/ahwootech/BRUTAL). It simulates falling sand/water on a 2d grid.

## Controls

- `1` - Sand
- `2` - Water
- `3` - Stone
- `4` - Erase
- `Left Click` - Paint material
- `Right Click` - Drop explosive
- `<` - Decrease brush size
- `>` - Increase brush size
- `R` - Clear grid
- `Esc` - Quit

## Built with BRUTAL

This project uses BRUTAL, a free and open source C# game development framework by
[Ahwoo](https://www.ahwoo.com/), available at <https://github.com/ahwootech/BRUTAL>.
